# Globe textures

- `earth-day-2048.jpg` — NASA Blue Marble imagery (NASA Visible Earth, public domain). Downloaded from the three-globe example assets (`unpkg.com/three-globe/example/img/earth-blue-marble.jpg`) because eoimages.gsfc.nasa.gov refused the connection from this box; resized from 4096×2048.
- `earth-night-2048.jpg` — NASA Earth at Night / city-lights imagery (public domain), same route (`earth-night.jpg`), resized.
- `earth-epic.webp` — [NASA DSCOVR / EPIC natural-color frame, November 22, 2026](https://epic.gsfc.nasa.gov/archive/natural/2026/11/22/jpg/epic_1b_20261122190501.jpg), displayed when the 3D globe cannot render or is still loading.

Decorative base imagery only. The day/night split on the globe is computed from the current sun position; nothing on the globe is a measured space-weather value.
