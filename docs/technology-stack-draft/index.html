Six layers, one stack.

FractalFS

A recursive filesystem that retrieves data by semantic resonance. Tagged, fractal, and structurally aware.

L04In development

FCAI-Core

An alignment engine for recursive AI. Guides behavior using structural resonance—rooted in fractal logic and ethical coherence.

L05In development
