LSFM vs HL-3.

LSFM Interpretation of Regime Transitions in HL-3 Disruption. Prediction (hypothesis).

Download the manuscript ↗
Status Unreviewed preprint (Zenodo)Status Hypothesis

02 / The paper

Correction · Nov 2026

The galaxy-fit claims in this work have been withdrawn. New pre-registered tests on SPARC rotation curves found no effect, and corrected versions of the affected papers and Zenodo records are being issued.

Read the correction ↗

Recent disruption prediction on the HL-3 tokamak (Yang et al., Nuclear Fusion 2025) revealed systematic drift across five operational regimes, necessitating Predict-First Neural Network (PFNN) architectures for reliable performance. We propose an interpretation using the Log-Scaling Flow Metric (LSFM), a proposed measure of how far a system departs from recursive, log-periodic scaling, and read the five regimes as transitions in that metric. We hypothesize that lower-disruption regimes may sit in a particular LSFM range. We list six predictions that could be tested, including real-time χ monitoring for disruption avoidance. If confirmed, this could inform ITER commissioning under non-stationary conditions.

Note: a separate re-analysis of the ITPA H-mode database found that χ's correlation with confinement quality (H98) mostly comes from both quantities sharing τ_E (in preparation).
